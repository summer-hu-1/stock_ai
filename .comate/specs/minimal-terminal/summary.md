# AI 股票信息终端 - 重构总结

## 完成日期
2026-05-23

## 重构目标
将原多 Tab、多引擎、多因子的 AI 股票复盘系统，重构为极简商业化的 **「AI 股票信息终端」**。

## 核心成果

### 产品定位转变
- **从：** AI 股票分析系统（多因子、多 Agent、多 Pipeline）
- **到：** Bloomberg Terminal Lite × AI 市场翻译器
- **核心价值：** 帮用户过滤噪音、理解市场故事、形成交易剧本

### 新增文件（4 个）

| 文件 | 作用 |
|------|------|
| `core/trader_lang.py` | 系统/引擎输出 → 交易语言翻译层。将 "acceleration" 翻译为 "资金还在持续进攻"，将 "炸板率飙升" 翻译为 "今天追涨停的人大部分都被坑了" |
| `modules/hot_timeline.py` | 今日异动时间线生成器。基于板块涨幅排序模拟关键时间点的市场异动 |
| `core/minimal_analysis.py` | AI 蒸馏引擎。3 个核心功能：市场理解简报（80-120字）、市场主线记忆（5天叙事）、个股次日剧本 |

### 重构文件（2 个）

| 文件 | 变更 |
|------|------|
| `app.py` | 从 1552 行精简到 ~280 行。5 个旧 Tab → 2 个新 Tab。删除所有评分数值、因子展开展示、Agent 调试信息 |
| `ui/theme.py` | 新增 8 个 CSS 组件：pulse-hero-bar、brief-card、main-line-memory、timeline-list、risk-list、next-day-card、trader-card 等 |

### 两个新页面

**市场脉搏（免费）：**
1. 动态状态条（🟢🔴🟡 + 交易语言）
2. 主线 + 市场主题
3. AI 市场理解（80-120 字）
4. 今日异动时间线
5. 风险提醒

**AI 个股（暂无付费门控）：**
1. 明天怎么办？（次日剧本，放在最上面）
2. 主力还在吗？
3. 市场定位
4. 当前状态

### 语言规范

全部使用「交易语言」替代「系统语言」：
- ❌ "趋势强度 91/100" → ✅ "资金还在里面"
- ❌ "波动率放大" → ✅ "筹码开始不稳定"  
- ❌ "高位震荡" → ✅ "高位开始有人兑现"
- ❌ "市场情绪退潮" → ✅ "短线开始不好赚钱了"
