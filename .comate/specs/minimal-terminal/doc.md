# AI 股票信息终端 - 重构规格文档 v3

> **产品定位：Bloomberg Terminal Lite × AI 市场翻译器**
>
> 核心不是"分析"，是帮用户**理解市场、过滤噪音、形成交易剧本**。
>
> **Slogan：3 分钟，看懂今天市场。**

---

## 0. 产品哲学

### 0.1 产品本质

| 不是 | 而是 |
|------|------|
| AI 分析股票 | AI 帮用户理解市场故事 |
| 量化平台 | 市场信息蒸馏终端 |
| 多因子扫描 | 主线方向 + 次日剧本 |
| 展示数据 | 节省认知能量 |

用户真正痛苦的是：
- 信息太多 — 需要过滤
- 新闻太杂 — 需要蒸馏
- 看不懂主线 — 需要记忆
- 不知道风险 — 需要判断
- 分辨不了假热点 — 需要经验
- 没时间复盘 — 需要效率

### 0.2 AI 输出语言规范

**AI 必须「像交易员」，不是「像研报」。**

#### 禁止
- ❌ 量化术语：因子、多头排列、ATR、波动率、Beta、回撤、MACD 金叉
- ❌ 评分数字：91/100、趋势得分 85
- ❌ 系统感描述：趋势强度高、波动率放大、放量突破
- ❌ 研报套话：注意风险控制仓位、建议逢低布局、后市可期
- ❌ JSON 格式输出、列表分点

#### 强制使用「交易语言」

| 禁止 | 替换为 |
|------|--------|
| 趋势强度高 / 91/100 | 资金还在里面 |
| 波动率放大 | 筹码开始不稳定 |
| 放量突破 | 有资金开始抢筹 |
| 缩量回踩 | 抛压不重 |
| 高位震荡 | 高位开始有人兑现 |
| 市场情绪退潮 | 短线开始不好赚钱了 |
| 弱势下跌 | 已经开始有人抢跑了 |
| 量价齐升 | 资金持续在买 |
| 炸板率升高 | 追高的人今天全被埋了 |
| 涨停数减少 | 今天打板不好做 |

### 0.3 设计原则
- **前台极简，后台极重** — 用户只看到结果，永远看不到过程
- **不要"全面"，要"高频"** — 用户一天打开多次因为想知道市场有没有"变"
- **每新增一个模块，必须问：用户真的能感知到价值吗？** — 不能就删
- **"结果"比"过程"值钱一万倍**

## 1. 页面一：「市场脉搏」（免费 Tab）

### 1.1 功能目标
用户打开 3 分钟内理解：今天钱在哪、主线是什么、有没有风险、市场在交易什么故事。

### 1.2 UI 结构（从上到下）

#### 1.2.1 动态状态条

```
🟢 资金重新回流 AI
🔥 主线：AI 算力 / 铜缆高速连接
🧠 今天市场在交易：AI 算力业绩确定性 + 铜缆新技术预期
```

三种典型状态：
```
🟢 资金重新回流 AI                       ← 偏多
🔴 高位开始集体兑现                       ← 偏空
🟡 市场正在等新的主线                     ← 中性
```

**数据来源：** `market_sentiment` + `market_engine` → 交易语言翻译。

#### 1.2.2 AI 市场理解（80-120 字）

一段自然语言，回答用户最关心的三个问题：**钱去哪了、钱从哪跑了、有没有伪热点。**

```
今天资金明显回流AI算力方向，中际旭创、新易盛等核心票放量走强，
铜缆高速连接方向也出现联动。但半导体和新能源还在出货，说明
资金不是全面进攻，而是集中抱团AI。需要注意高位已经开始有人
兑现，明天如果板块内部分化，追高容易吃亏。
```

**禁止：** 列表、分点、标题、技术指标。

#### 1.2.3 市场主线记忆（新增，核心差异化功能）

AI 自动跟踪并生成过去 5 天的市场主线演化。

```
📜 过去 5 天市场在交易什么：

Day 1（周一）：机器人方向启动，资金试探性进场
Day 2（周二）：AI 算力接力，成为市场最确定的进攻方向
Day 3（周三）：铜缆高速连接异动，算是 AI 的延伸炒作
Day 4（周四）：高位开始出现分歧，部分资金选择兑现
Day 5（周五·今天）：资金没走，重新回流核心龙头
```

**价值：** 用户终于"看懂市场故事了"。不是看单日数据，而是理解市场叙事。

**实现：** 调用 DeepSeek，输入最近 5 天的板块和市场情绪数据，输出自然语言市场叙事。

#### 1.2.4 今日异动时间线

当天关键时间点的市场动作，最多 5 条。

```
09:35 AI 算力方向集体抢筹，中际旭创放量拉升
10:12 铜缆高速连接异动，沃尔核材涨停
13:45 北向资金回流 30 亿，主要加仓电子板块
```

**实现：** `modules/hot_timeline.py`，基于板块涨幅模拟异动时间点。

#### 1.2.5 风险提醒

最多 3 条，交易语言。

```
⚠️ 高位连板票今天炸板明显增多，追高的人全被埋了
⚠️ 创业板连续走弱，小票情绪在降温
⚠️ 从"大家一起赚钱"转向"开始互相收割"，短线小心点
```

**数据来源：** `market_engine.detect_danger_signals()` → 交易语言翻译。

## 2. 页面二：「AI 个股」（付费 Tab）

### 2.1 功能目标
回答用户最想问的：**明天怎么办？** 这才是付费点。

### 2.2 内容排序（按价值从高到低）

```
1. 明天怎么办   ← 核心付费，最大最上面
2. 主力还在吗？ ← 资金有没有撤？有没有抢跑？
3. 市场定位     ← 龙头/跟风/中军/补涨？
4. 当前状态     ← 最不重要，放最后
```

### 2.3 UI 结构

#### 2.3.1 搜索框
支持代码或拼音缩写，自动匹配股票名称。

#### 2.3.2 明天怎么办？（第一块，最大，核心付费）

```
📅 明天怎么办？

如果高开（>2%）：
  放量站稳今天高点 → 可以继续拿着
  冲高回落且炸板 → 该减就减

如果平开或小低开：
  半小时内翻红 → 可能是弱转强，关注
  持续水下震荡 → 先看戏

如果大幅低开（<-5%）：
  15 分钟内不能站回 -3% 以上 → 该止损就止损

⚠️ 关键风险：
  明天如果板块分歧，这票可能冲高回落，
  不要追高。
```

**生成逻辑：** 当前状态 + 近期走势 + 板块预期 → 具体条件 + 具体动作。**禁止任何套话。**

#### 2.3.3 主力还在吗？（第二块）

```
💰 主力没走，趋势资金还在里面
📈 已经连续 3 天放量，有大资金在买
🧠 判断：机构控盘，短期不容易深调
```

核心回答：**资金有没有撤？** 基于量价数据分析。

#### 2.3.4 市场定位（第三块）

```
🎯 在 AI 算力板块里，这票是中军角色，不是龙头但走得最稳
🏆 板块内部排名：龙二
📎 跟风关系：跟着中际旭创走，但弹性更强
```

#### 2.3.5 当前状态（第四块，放最后）

```
📌 状态：资金还在持续进攻
📊 短线做多情绪还在
⚠️ 个股风险：高位开始有人兑现（中）
```

**状态取值（交易语言）：**

| 内部状态 | 对外展示 |
|----------|----------|
| acceleration | 资金还在持续进攻 |
| trend_follow | 稳步向上，做多情绪还在 |
| breakout | 有资金开始抢筹 |
| reversal_reclaim | 可能有资金在试盘 |
| consolidation | 方向不明确，先看看 |
| panic_distribution | 抛压在加大，要小心 |
| decay | 短线开始不好做了 |

## 3. 模块保留/删除清单

### 3.1 保留

| 模块 | 用途 |
|------|------|
| `market_sentiment` | 市场情绪数据 |
| `market_engine` | 情绪周期 + 危险信号 |

| `deepseek` | AI 蒸馏调用 |

### 3.2 新增

| 文件 | 用途 |
|------|------|
| `modules/hot_timeline.py` | 今日异动时间线 |

| 路径 | 原因 |
|------|------|
| `agents/` | 工程感过强，用户无感 |
| `factors/` | 因子系统，用户无感 |
| `signals/` | 信号系统，用户无感 |
| `core/analysis_pipeline.py` | 过度架构 |
| `modules/morning_analyzer.py` | 功能被替代 |
| `leaders/` | 简化为工具函数即可 |

## 4. 验收标准

| # | 标准 |
|---|------|
| 1 | 打开首页，顶部是动态状态（🟢🔴🟡 + 交易语言），不是系统标签 |
| 2 | 有"市场主线记忆"——过去 5 天市场叙事一目了然 |
| 3 | 所有文案使用交易语言，无技术指标、无评分数字、无 JSON |
| 4 | AI 个股页次日剧本在最上面，包含具体条件，无套话 |
| 5 | 没有任何后台模块名、文件路径、数据结构暴露给用户 |
| 6 | 像 Bloomberg Terminal 简化版，不像内部后台 |
| 7 | 顶部有"动态刷新感"，用户会想回来看看变了没有 |
