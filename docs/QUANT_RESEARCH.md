# Quant Research Lab · 离线研究 MVP

这是 \`stock_ai\` 的独立 Streamlit 研究入口，不覆盖原来的市场脉搏、个股分析页面。没有实盘交易、QMT、券商订单或自动网络行情连接。

## 运行

\`\`\`bash
python -m pip install -r requirements.txt
python -m streamlit run research_app.py
\`\`\`

CSV 使用 UTF-8；必需字段：\`date,open,high,low,close,volume\`，也接受同义中文列名。日期须唯一，行情非空，OHLC 关系正确。不要将本地测试生成的虚拟数据用于投资判断。

## 策略与执行假设

- MA 快线 > 慢线时满仓持有同一标的，否则空仓。
- 用上一交易日收盘形成信号，于下一交易日开盘执行。持仓收益用 open[t] 到 open[t+1]，样本末尾按最后开盘价格强制平仓。
- 单边佣金、滑点和卖出税费均可配；单位 bps。默认卖出税 0 是 ETF 示例，股票需按照具体市场及日期单独配置。
- 基准是同区间开盘价买入并持有、未扣费；不能视为策略同条件优势比较。
- 输出累计收益、最大回撤、零无风险利率夏普、建平仓次数、暴露度、净值与逐日计算表。
- 尚未模拟最低佣金、涨跌停或停牌导致无法成交、复权及分红现金流、多标的资金约束、冲击成本、成交量约束、样本内外验证及幸存者偏差。

## 验证

\`\`\`bash
python -m pytest tests/test_quant_research.py tests/test_hot_timeline.py -q
\`\`\`

测试均使用合成数据，只验证规则一致性，不证明历史超额收益。实验可复现实盘能力需要更严格的时间、成本和可成交性模拟。

## CODE-001：盘中异动真实性

旧版将板块日涨幅随机映射为个股异动和固定时间戳。现改为只接受含事件时间、带时区的来源时间和 URL 的实际事件输入；没有证据就返回空列表，UI 显示“暂无可核实的分时异动数据”。这仅验证来源字段完整，不代表第三方内容必然准确。
